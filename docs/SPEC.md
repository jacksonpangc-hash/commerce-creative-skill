Do not redistribute original Clipcat binaries, instruction bodies, vendor data, credentials or private endpoints. The initial local-only phase is complete. ## 0.2 商业创作闭环（用户已授权实施，2026-10-26）

上一轮水杯只是接口试跑，不能视为商业内容验收。保留 version-1 技术试跑；version-2 用于定向分析、策略探索、灵感激发后的商业生产。原有供应商、隔离、密钥、授权和不自动重试的要求全部保留。

- AC21 商品：明确 real/fictional，结构化声明及证据范围；品类、竞品和虚构设定不能作为真实 SKU 的验证证据。虚构商品仅交付带披露的概念演示。未知销量、价格、配料、效用保留未知。
- AC22 策略：目标人群、消费情境、购买任务、传播目标、主角度、钩子、证明方式、行动指令、来源和待证假设；探索与灵感保留可比较的不同创意。
- AC23 分镜：逐镜头角色、目的、声明引用、可观察的证明画面、口播/字幕、商品外观锁和参考素材。验证时长/角色/来源完整性；校验不能宣称懂得文本真假。
- AC24 生成：导出携带分镜与证据文件指纹的请求，修改脚本、文件或提示词后重新准备；选定供应商，不暗中切换。没有真实图只能做概念演示，不能声称实物还原。
- AC25 本地分析与制作：实际探测视频规格、全程解码、带时间戳采样帧及音轨导出；支持本地标准化拼接、外部配音/音乐、确定性字幕与概念披露。保留原片，派生文件明确记录变换，不把补边/重采样说成原生输出。
- AC26 验收与迭代：技术规格、商品一致性、钩子兑现、购买理由、文案/声音/连续性分开。成片及审阅记录绑定指纹；未知、漏看、漏听或失败不能通过。输出只改失败镜头的修改建议，不自动付费重试。
- AC27 网络：修复 TUN fake-DNS 下载阻塞；只连接验证过的公网 IP，TLS 校验原主机名，不跟随重定向、不传模型密钥、不放宽 SSRF 防护。公共解析为显式选项。
- AC28 交付：中文 Skill 与完整绿豆饼概念案例，来源可追踪、可离线复现校验；测试、工具可运行和各供应商真实账户验收分别报告。没有购买私有素材库，不能声称覆盖或效果超过供应商。

本轮实施不调用付费服务、不发布社交内容。新视频生成需展示具体新请求、次数、估算与预算后取得新授权；已使用的水杯单次预算不复用。
