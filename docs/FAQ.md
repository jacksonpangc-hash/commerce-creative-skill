# 常见问题

**这是离线视频模型吗？**

本地运行的是编排、校验、状态保存与可选拼接。模型生成和供应商数据仍调用云服务；未配置密钥时，可以完成离线输入校验和计划准备。

**需要同时购买所有服务吗？**

只配置当前选择的服务。MiniMax、火山方舟、OpenAI、Clipcat、蝉镜和有米云的账号、权益与计费各自独立。ChatGPT 订阅不能视为模型 API 余额。

**能否不使用 Clipcat 的 API Key？**

视频可以直连 MiniMax H3 或 Seedance，图片可以选三家直连服务。使用 Clipcat 原数据、素材库、排期或 TikTok 通道时仍依赖原客户端和服务权益；它的私有后端没有被替换成本地数据库。

**蝉妈妈是否直接输出完整分镜？**

当前确认的接口是蝉镜创意雷达品类简报。脚本和分镜由当前 Agent 编写，独立于生成服务。不能将简报称为逐条视频 GMV 或商家达人原始数据。

**所有平台是否已经实测发布？**

尚未。适配器、离线契约和 Intel Mac 启动已测试；真实浏览器登录、上传、定时与公开作品仍需单独验收。`submitted_unverified` 需要人工核对原作品。

**生成失败会自动换便宜模型吗？**

不会。保留用户选择与原回执。超时可能发生在供应商已经接收任务之后，先查原任务，避免重复扣费或重复发布。

**电脑休眠还能定时运行吗？**

本地执行需要电脑和依赖持续运行。Clipcat 原云端排期沿用其服务；新 Python 适配器不会自动被它的云调度器执行。

**为什么没有真实案例和效果数字？**

目前没有完成真实付费与发布验收，不展示未经证实的案例、ROI、销量或爆款承诺。已有示例只用于说明输入格式。
