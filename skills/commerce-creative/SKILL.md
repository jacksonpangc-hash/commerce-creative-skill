# 电商素材创作与多平台发布 0.2

使用本技能组织已获授权的多服务创作流程，同时保留原 Clipcat 技能与客户端。流程在本地编排，并连接云端 API；它不提供离线视频模型，也不包含供应商的私有后端。

## 选择当前阶段

1. 核对当前项目根目录、商品事实、目标平台、语言及交付内容，沿用用户已确认的选择。区分真实商品与获准虚构的概念商品；概念交付显示披露。只有获准配置项目后，才初始化项目内的本地状态。
2. 做品类创意洞察时，可选蝉镜创意雷达（蝉妈妈相关数据来源）、原 Clipcat 调研服务或有米云。蝉镜返回品类简报，不提供逐条视频 GMV 记录或本地视频拆解。保留报告原文与来源。
3. 商业创作先读[商业工作流与验收](references/commercial.md)：定向分析回答具体素材问题，策略探索比较不同购买理由，灵感激发给出有依据的原创方向。当前 Agent 完成判断与可编辑 version-2 分镜，保存人群、情境、钩子、证明、行动指令及证据。实现不额外调用一个隐藏的文本模型；真实 SKU 的每项声明核对商品证据，品类/竞品介绍只作参考。编写格式见[分镜格式与编写要求](references/storyboard.md)。
4. 视频服务可选原 Clipcat、直连 MiniMax H3（默认）或火山方舟 Seedance 2.5；图片服务可选 MiniMax image-01、火山方舟 Seedream 5.0 pro 或 OpenAI GPT Image 2.5。各家素材与编辑限制不同，只读取[服务连接说明](references/providers.md)中当前选用的部分。
5. 使用 Python 3.10 或更新版本运行已安装的 `scripts/commerce.py`；通过本仓库安装时，安装清单会记录解释器位置。用 `--help` 查看命令用法。macOS 自带 Python 可能过旧。需要执行、恢复、暂存或发布时，读取[命令使用流程](references/cli.md)。

## 审核与执行

`prepare` 完全离线：校验项目文件与配置、记录文件指纹，并保存不可随意变更的本地计划；不会联网或上传。向用户展示所选服务、完整提示词与分镜、素材、发布账号、执行时间，以及有来源依据的费用。费用未知时保留 `UNKNOWN`，不能填成零或虚构报价。

用户批准这些具体操作后才能执行。命令参数用于记录已有授权，Agent 不能通过自行添加参数来制造用户同意。发布与创建定时任务需要各自明确的授权范围。已明确授权的自动化，只能在约定账号、内容和预算内覆盖后续执行。

使用 Clipcat 原始生成接口或发布 TikTok 时，首次执行会返回服务端核对清单与 `server_confirm_id`。展示清单，等待用户后续明确回复，再执行 `confirm-clipcat`，保留服务端的两阶段确认。Clipcat 的 dry-run 可能上传素材，不能把它当作离线预览。

提交后保留原任务。超时或出现 `submission_unknown` 时，先查供应商历史记录或原作品，再决定是否新增提交。用本地任务 ID 查询，不借用其他项目的会话或任务历史。在签名链接失效前下载成功结果；未经授权，不将结果上传到 Clipcat 云端素材库。

## 交付与验收

商业创作使用 version-2 格式；version-1 保留为技术试跑，不能据此宣布商业通过。导出后修改提示词会失去分镜绑定，应修改真源并重新导出。需要商品还原时先核对同一 SKU 的已授权实物图；概念图只能支持概念外观一致性。

下载后用 `media-inspect` 获得实际规格、全程解码结果、采样帧和可试听音轨；本地素材拆解也从这些证据开始，时间码来自实际文件。采样证据用于定位问题，最终需观看整片、听音并填写 `review-template` 的实际观察。`render` 可标准化拼接、烧录字幕和概念披露，并接入用户选定的本地配音/音乐；保留原片，明确派生变换。通过 `acceptance-check` 后才称内容审阅通过，失败只提出对应镜头的修改方案，新付费生成另行确认。

说明实际服务、文件、来源、已知费用与用量，以及未完成项。分别报告本地测试、服务账户、生成成功、内容审阅、实物一致性、真实投放效果和发布状态。没有私有素材数据授权时说明覆盖未知，不把公开搜索当作同等数据库。SAU 退出码为零仅记为 `submitted_unverified`，仍需到创作者中心核对原作品。遇到登录或平台验证时由用户完成。
